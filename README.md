# Пульт ноутбука

Управляйте ноутбуком с телефона по Wi-Fi: выключение и сон, трекпад с прокруткой, клавиатура, громкость, видео, таймер «уснуть под сериал», общий буфер обмена.

Работает на Windows, macOS и Linux. Ничего, кроме Node.js, ставить не нужно.

## Установка (Windows)

1. Нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив **в постоянную папку**, например `Документы\Пульт`. Из «Загрузок» лучше не запускать: автозапуск привязывается к этой папке.
2. Дважды щёлкните **`install-windows.cmd`**. Если Node.js не установлен, файл поставит его сам.
3. Если Windows спросит про брандмауэр, разрешите доступ **в частных сетях**.
4. В окне появится ссылка вида `http://192.168.1.18:7777/#…`. Откройте её на телефоне, подключённом к тому же Wi-Fi, и добавьте страницу на экран «Домой».

Дальше пульт запускается сам при входе в Windows.

## macOS и Linux

Установите [Node.js](https://nodejs.org) 18 или новее, распакуйте архив и выполните в папке:

```
node install.js
```

Для трекпада нужен `cliclick` на macOS (`brew install cliclick`) или `xdotool` на Linux.

## Обновления

Пульт сам проверяет обновления раз в полчаса. Когда выходит новая версия, он скачивает её, перезапускается, и телефон подтягивает новый интерфейс. Пока вы пользуетесь пультом или стоит таймер, обновление ждёт.

Не хотите ждать — вкладка **Ещё → Проверить обновления**: пульт сразу скачает новую версию, перезапустится, и страница обновится сама. Там же видно текущую версию.

Выключить автообновление можно строкой `"autoUpdate": false` в `config.json`.

## Полезное

- `config.json` — токен доступа и свои кнопки-команды (пример в `config.example.json`). Не отправляйте его никому: по токену можно управлять ноутбуком.
- `pcr.log` — журнал и ссылка для телефона.
- `node install.js status` — проверить автозапуск, `node install.js remove` — убрать его.

## Для автора: как выпустить обновление

1. Измените файлы.
2. Увеличьте `version` в `package.json` (например, `1.0.0` → `1.0.1`). Без этого у друзей ничего не обновится.
3. `git commit -am "что поменял" && git push`.

Через полчаса максимум у всех будет новая версия.
